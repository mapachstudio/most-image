Most Image portable mode

While this file sits next to photocraft.exe, Most Image keeps its preferences, brush presets,
crash-recovery autosaves and startup state in the Most ImageData folder beside it, and writes
nothing to %APPDATA% or %LOCALAPPDATA%. Copy the whole folder to move Most Image with its settings.

Delete this file to use the normal per-user folders instead: %APPDATA%\Photocraft for settings
and %LOCALAPPDATA%\Photocraft\Recovery for crash-recovery autosaves. If Most ImageData can't be
written (for example on a read-only drive), Most Image says so and uses those folders instead.
